# Обозначения фигур

- **N** — конь  
- **B** — слон  
- **K** — король  
- **Q** — ферзь  
- **P** — пешка  
- **R** — ладья  

---

# 1. Класс фигур (базовые фигуры)

Базовый класс, от которого наследуются все остальные фигуры.

В классе хранятся:

1. **Функция определения битых полей**
2. **Функция вычисления достижимых полей** (куда фигура может пойти)
3. **`char name`** — обозначение фигуры (N, B, K, Q, P, R)

---

# 2. Класс каждой фигуры

Каждая конкретная фигура содержит:

1. **Переопределённую функцию расчёта битых полей**
2. **Отдельную функцию достижимых полей для пешки**  
   (потому что логика ходов пешки отличается)

---

# 3. Класс `Field` (клетка доски)

Одна клетка шахматной доски содержит:

1. **Цвет клетки** (белая / чёрная)
2. **Цвет фигуры** (если на клетке стоит фигура)
3. **Указатель на базовую фигуру**  
   (`Figure*` или `nullptr`)

---

# 4. Класс `Board` (шахматная доска)

Содержит:

## 4.1. Массив клеток

```cpp
Field board[8][8];
```

## 4.2. Проверка хода

При проверке хода выполняются:

1. Проверка, что ходит **правильная фигура**  
   (совпадает цвет и введённое обозначение)
2. Проверка, что целевая клетка входит в **список достижимых полей**
3. Проверка отсутствия **преград на пути хода**  
   (своя логика для каждой фигуры)

## 4.3. Битые поля
## 4.4. Сторону, которая должна сейчас ходить

Две булевые доски:

- битые поля **белых**
- битые поля **чёрных**

## 4.5. Функция хода

При выполнении хода:

0. Проверка **уникальности хода**
1. Вызов  
   ```cpp
   is_possible(фигура, координаты_1, координаты_2);
   ```
2. Перестановка фигур на клетки (`Field`)
3. Обновление таблиц битых полей **белых и чёрных**
